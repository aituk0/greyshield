Политика конфиденциальности

Дата обновления: 17 октября 2026 года

В этой политике объясняется, какие сведения GreyShield использует для блокировки рекламы, где они хранятся и с кем могут передаваться.

Какие сведения использует расширение

  • Домен открытой страницы — чтобы применить подходящие фильтры, исключения и пользовательские правила. Полный URL страницы не сохраняется.
  • HTML-тег, безопасные имена классов и идентификатор элемента — только когда пользователь сам запускает выбор элемента. Они нужны, чтобы сформировать CSS-селектор.
  • Настройки, сайты-исключения, пользовательские CSS-селекторы и кэш фильтров.
  • Число заблокированных сетевых запросов, которое показывает Chrome для текущей вкладки, и число совпадений с пользовательскими правилами.

Хранение и использование

Домен страницы используется локально для основной функции блокировки. Настройки, исключения, созданные пользователем селекторы и кэш фильтров хранятся в Chrome с помощью chrome.storage. Счётчик сетевых блокировок предоставляет Chrome. GreyShield не отправляет разработчику домены страниц, содержимое страниц, выбранные элементы или статистику. Расширение не использует аналитику, рекламные профили или учётные записи.

Загрузка списков фильтров

При запуске, по ежедневному расписанию или после ручной команды GreyShield загружает текстовые списки правил с EasyList, GitHub (RU AdList) и серверов AdGuard. Эти серверы получают обычные технические данные HTTPS-соединения; GreyShield не добавляет к запросам адрес посещаемой страницы или содержимое вкладки. Поставщики списков могут обрабатывать технические журналы соединений согласно собственным политикам. Загружаемые файлы содержат правила фильтрации, а не исполняемый код.

Передача данных и требования Chrome

GreyShield не продаёт сведения и не передаёт их рекламным сетям, брокерам данных или аналитическим компаниям. Информация, полученная через API Chrome, используется только для основной функции GreyShield и в соответствии с Chrome Web Store User Data Policy, включая требования Limited Use.

Удаление

Пользователь может удалить отдельные правила и сайты-исключения в настройках GreyShield. Удаление расширения через Chrome удаляет сохранённые им локальные данные.
