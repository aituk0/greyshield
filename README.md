# GreyShield — политика конфиденциальности

Публичная статическая страница политики конфиденциальности расширения GreyShield. Страница не использует сторонние скрипты, аналитику или cookie.

## Публикация

Для первого запуска откройте **Settings → Pages** в репозитории `aituk0/greyshield` и выберите **GitHub Actions** в разделе **Build and deployment → Source**. После этого workflow `Deploy to GitHub Pages` будет публиковать корневую `index.html` при каждом обновлении ветки `main`.

Ожидаемый адрес: https://aituk0.github.io/greyshield/.
